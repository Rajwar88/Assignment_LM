    Create transaction requests¶

    POST https://api-sdk.lmnl.dev/api/wallet/send-many-transaction

    API Reference Update — Security & Compliance Integration

    Feature Update: Integrated cube3 Security Inspector API for real-time destination address screening.
    New Parameter: screeningFlag (boolean) added to Send-Many-Transaction-Object-Request.
    Behavior: Automatically screens destination addresses for cyber, fraud, and compliance threats. Blocks the transaction if any destination address has a combined Risk Score > 80 and returns HTTP 422 Unprocessable Entity (RISK_SCREENING_FAILED).

    ## Description This API is a request to execute a single or multiple transactions from a v1 withdrawal wallet to specified destination address(es). EVM chains support transfers to a single address, while UTXO chains support transfers to one or more addresses. You can transfer funds in either native coin or token in a single request. For opt-in asset chains like **XRP** and **Stellar (XLM)**, use `wallet.transactionType = "enableToken"` to establish a one-time trust line before sending or receiving token assets. With the integration of **Cube3 Security Inspector**, destination addresses can be evaluated for security threats (such as sanctioned entities, drainer contracts, and malicious actors) prior to broadcasting transactions on-chain. --- ## Parameter Guidelines & Validation Rules Accepted parameter values: 1. The `transactions.recipientsData.recipients[].address` parameter must have a valid address length (> 0). It will not accept any null value or empty `String` value. 2. The data type of `transactions.recipientsData.recipients[].amount` is updated to `String` and must be a positive decimal string. It will not accept empty string, null, or number value. 3. The `transactions.recipientsData.sequenceId` parameter is a required unique tracking identifier (UUID format) generated by the client. 4. **[NEW]** The `screeningFlag` parameter is a `Boolean` (`true` or `false`). - When set to `true`, all destination addresses in `transactions.recipientsData.recipients[]` are evaluated via Cube3 Inspector API before broadcast. - If any address has a combined **Risk Score > 80**, the transaction request is aborted and returns **HTTP 422 Unprocessable Entity** with error code `RISK_SCREENING_FAILED`. - When set to `false` or omitted, no screening takes place and standard payout rules apply. 5. **Asset Enablement (`wallet.transactionType`)**: - Set to `"enableToken"` to create a trust line for non-native assets on XRP (`RLUSD`) or Stellar (`USDC`). - When `wallet.transactionType` is `"enableToken"`, `transactions.recipientsData.recipients` must be an empty array `[]`. --- ## Parameter Reference Table | Parameter Path | Data Type | Requirement | Description | | :--- | :--- | :--- | :--- | | `wallet` | `object` | Required | Wallet details object (`coin`, `walletId`, `allToken`, `tokenOptions`). | | `wallet.coin` | `string` | Required | Abbreviated cryptocurrency symbol (e.g., `eth`, `btc`, `sol`, `bnb`, `xrp`, `xlm`). | | `wallet.walletId` | `integer` | Required | Unique identifier of the source withdrawal wallet. | | `wallet.transactionType` | `string` | Optional
    *(Default: `"transfer"`)* | Transaction operation type (`"transfer"` or `"enableToken"` for XRP/XLM trust lines). | | `wallet.allToken` | `boolean` | Optional | Set to `true` when transferring non-native token assets. | | `wallet.tokenOptions.tokenName` | `string` | Optional | Token symbol name (e.g., `USDC`, `RLUSD`). | | `wallet.tokenOptions.tokenAddress` | `string` | Optional | Contract address (EVM) or `.` (XRP) / `:` (XLM). | | `transactions.recipientsData.recipients` | `array[object]` | Required | Array of recipient objects (`address`, `amount`, `data`). Must be `[]` for `enableToken`. | | `transactions.recipientsData.recipients[].address` | `string` | Required | Target destination wallet address. | | `transactions.recipientsData.recipients[].amount` | `string` | Required | Positive decimal string representing transfer amount. | | `transactions.recipientsData.sequenceId` | `string` | Required | Unique system sequence UUID generated by the client for tracking. | | **`screeningFlag`** | boolean | Optional
    *(Default: `false`)* | **[NEW]** Controls pre-transaction Cube3 risk screening. | | `feeLevel` | `string` | Optional | Gas fee tier (`slow`, `market`, `aggressive`, `custom`). | | `evmCustomfee.maxPriorityFeePerGas` | `string` | Optional | Priority gas fee in Wei. | | `evmCustomfee.maxFeePerGas` | `string` | Optional | Maximum gas fee in Wei. |

    === "Go (net/http)" 
    package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "io"
    "net/http"
)

func main() {
    url := "https://api-sdk.lmnl.dev/api/wallet/send-many-transaction"
    payload := map[string]interface{}{
        "wallet": map[string]interface{}{"coin": "eth", "walletId": 14999},
        "transactions": map[string]interface{}{
            "recipientsData": map[string]interface{}{
                "recipients": []map[string]string{
                    {"address": "0x017208E63ec387461C7e8f20bA9C6F9Dec939cfe", "amount": "0.008"},
                },
                "sequenceId": "08d5893b-0066-4619-b7af-a5bae54205d5",
            },
        },
        "screeningFlag": true,
        "feeLevel":      "market",
    }

    jsonValue, _ := json.Marshal(payload)
    req, _ := http.NewRequest("POST", url, bytes.NewBuffer(jsonValue))
    req.Header.Set("Content-Type", "application/json; charset=utf-8")
    req.Header.Set("Authorization", "Basic your_api_credentials")

    client := &http.Client{}
    resp, err := client.Do(req)
    if err != nil { panic(err) }
    defer resp.Body.Close()

    body, _ := io.ReadAll(resp.Body)
    fmt.Println(string(body))
}
